自有产品 · 运行中 · 2026

Ada：用 n8n 和 AI 做我的渠道营销

问题
每天为 YouTube、Instagram、TikTok 和 LinkedIn 制作视频、封面和文案，会占满整个晚上；一旦哪里出错，当天就什么都发不出去。
我做了什么
Ada，一个在 n8n 中按两个周期运行的系统。每周它请 ChatGPT 写故事，并准备剧集、短视频、帖子和推广活动；每晚它回顾当天，如果值得，就准备一条新闻视频。ChatGPT 负责写故事和生成图片，Google AI Studio 负责配音，剪辑、片段和封面来自我自己的视频引擎。所有内容进入一个队列：发布前一天晚上 8 点，它检查封面、文案、时间、每个渠道每天最多三条、14 天内不重复话题，并发一封邮件，每条内容都有一个“停止”按钮。
结果
审核通过的内容通过 Buffer 和 YouTube API 发布，视频自动归档。有错误和告警日志：如果图片或配音额度用完，它会记录时间，等有额度时再继续；如果某个渠道失败，会提示手动上传。审核和告警已上线；自动发布正在测试中。

n8n · OpenAI API · Google AI Studio · Buffer · YouTube API · rclone

Club Byte：讲给 8 到 12 岁孩子听的科技

开源 · Arce Data Lab · 2026

把应用部署到 DEV 和 PRO 的自建平台

问题
每个应用都在服务器上手工部署，域名、登录和备份各用一套做法。
我做了什么
一个在同一台服务器上为每个应用提供测试环境和正式环境的系统。应用通过一个清单文件接入，系统自动创建它的路径、Keycloak 用户组、带证书的域名，并从 GitHub 镜像部署。

自有产品 · Sindri 的一部分 · 2026

Efesto：让 Sindri 读懂工厂

问题
设备状态、良品和不良品数量、报警信息都留在各自的 PLC 或 SCADA 里，离 ERP 很远，而要连接它们通常意味着要在工厂里开放端口。
我做了什么
一个只读的车间代理程序，带 16 种连接器：OPC UA、Modbus、Siemens S7、Rockwell、Beckhoff、Omron、MQTT、MTConnect、BACnet、历史数据库 SQL、文件和电子秤等。连接从工厂向外发起，断网时先存储再补发，工厂的地址和密码绝不外传。
结果
用 22 台模拟设备测试：106 个数据点全部送达 Sindri。一台设备掉线，其他设备照常工作。尚未连接真实工厂。

Python · OPC UA · Modbus · Siemens S7 · MQTT · SQLite · Docker
