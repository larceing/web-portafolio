Forja：离线可用的平板预约应用

问题
一家在医院管理患者预约的企业，一直用一个基于电子表格的应用，已经不够用了，而且医院里不一定有信号。
我做了什么
我把它重写成一个有自己数据库的 Web 应用，外加一个离线可用的平板应用：数据先存在本地，把修改排队，网络恢复后以带版本的事件同步。
结果
日程、患者、服务、付款、文档和提醒集中在一处，还有一个冲突处理界面，用来决定两台设备修改同一内容时以哪个为准。部署在我自己的服务器上。

Next.js · TypeScript · PostgreSQL · Prisma · React Native · Docker
