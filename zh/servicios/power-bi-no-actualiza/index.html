你的 Power BI 报表无法刷新：原因与解决方法

打开报表发现数据还是昨天的，或者收到一封“刷新失败”的邮件。几乎总是下面六个原因之一，大多数几分钟就能解决。先在 Power BI 服务中查看语义模型的刷新历史记录：错误信息就在那里。如果找不到原因，我和你一起排查。

获取报价

最常见的六个原因

按出现频率从高到低排列。每一个都附有判断线索和处理方法。

原因 1

凭据过期

有人更改了数据库、Microsoft 365 或报表所用账户的密码。

  • 在 Power BI 服务中打开语义模型设置，进入“数据源凭据”，重新登录。
  • 使用密码不会过期的服务账户，而不是个人账户。

原因 2

网关没有响应

数据来自公司的服务器或文件夹，错误信息提到网关（gateway）。

  • 确认安装网关的电脑已开机、已联网且没有休眠。
  • 更新网关：Microsoft 几乎每个月都会发布新版本。
  • 最好装在服务器上，而不是某个人的笔记本电脑上。

原因 3

文件被移动或改名

报表读取的 Excel 或 CSV 被人换了文件夹、文件名或工作表。

  • 在 Power Query 的“数据源设置”中重新指定路径。
  • 把文件放在 SharePoint 或 OneDrive，并通过网址连接：这样就不需要网关。

原因 4

某一列变了

错误信息说找不到某一列（“The column … of the table wasn’t found”）。

  • 有人在 Excel 或 ERP 视图中重命名或删除了这一列。
  • 调整用到这一列的 Power Query 步骤，或者约定数据源保持列名不变。

原因 5

计划刷新自动关闭了

报表停止刷新，没有新的错误，计划刷新显示为已禁用。

  • 连续失败四次后 Power BI 会禁用计划刷新；如果两个月没有人打开报表，也会暂停。
  • 解决原因后打开报表，重新开启计划刷新。

原因 6

耗时太长

错误信息提到超时或大小限制。

  • 使用 Power BI Pro 时，每次计划刷新最长两个小时。
  • 删除不用的列和行，在数据源端筛选，并考虑增量刷新。

包含内容

诊断

检查刷新历史记录、网关和凭据，直到找到故障原因。

修复

解决根本原因：凭据、路径、Power Query 步骤或网关配置。

不会断的路径

把 Excel 文件迁到 SharePoint 或 OneDrive，移动文件不再导致报表出错。

再次失败时提醒

设置失败通知邮件，发给负责修复的人，而不只是报表所有者。

更轻的报表

如果刷新太慢，精简数据和 Power Query 步骤，让它几分钟内完成。

常见问题

为什么我的 Power BI 今天不刷新？
先看语义模型的刷新历史记录：错误信息通常会说明原因。最常见的是凭据过期、网关关闭或文件被移动。
如果是 Power BI 本身出问题呢？
有可能，但很少见。查看 Power BI 服务状态页面。如果有故障，什么都不用改：Microsoft 修复后刷新会恢复正常。
每天可以刷新几次？
使用 Power BI Pro，每天最多 8 次计划刷新。使用 Premium Per User 或 Fabric 容量，最多 48 次。
请你修复要多少钱？
取决于原因。告诉我出现了什么错误，开始之前我会给你一份固定报价，无需承诺。
