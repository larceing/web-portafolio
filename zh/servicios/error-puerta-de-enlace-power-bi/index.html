Power BI 网关错误：原因和解决方法

数据网关是让 Power BI 服务读取公司内部数据的程序，比如 SQL Server、ERP 或共享文件夹。网关出错，报表就无法刷新。几乎总是下面六个原因之一。先看刷新历史里的错误信息，再看网关应用的“状态”页。如果还是找不到原因，我和你一起排查。

获取报价

最常见的六个原因

每个原因都附有识别线索（通常就是错误文字）和处理方法。

原因 1

网关离线

错误提示“Your data gateway is offline or couldn’t be reached”，或在“管理连接和网关”中显示离线。

  • 确认安装网关的电脑已开机、能上网且没有休眠。微软不建议把网关装在笔记本电脑上。
  • 打开网关应用，在“服务设置”里重启网关。
  • 如果几个月没动过，请更新：微软只支持最近的六个版本。

原因 2

缺少数据源连接

设置计划刷新时选不了网关，或错误提示没有为数据源配置网关。

  • 在“管理连接和网关”中，为报表用到的每个公司内部数据源创建连接，并且都放在同一个网关上。
  • 服务器和数据库名称要和 Power BI Desktop 里完全一样：那里用的是 IP 或 SERVER\INSTANCE，这里也要一样。
  • 请管理员把你加为该连接的用户。

原因 3

连接里的凭据不对

错误提示“Invalid connection credentials”或“Login failed for user”。

  • 使用网关时，凭据不在语义模型里，而是在“管理连接和网关”的连接中修改。
  • 确认身份验证方式（Windows 或基本）与数据源要求的一致。
  • 使用密码不会过期的服务账户。

原因 4

能连到网关，但连不到数据源

错误提示“We reached the data gateway, but the gateway can’t access the on-premises data source”，或出现代码 DM_GWPipeline_Gateway_DataSourceAccessError。

  • 在网关所在的电脑上打开 Power BI Desktop 并刷新报表：如果在那里也失败，问题就在这台电脑上。
  • 在这台电脑上安装数据源需要的驱动，比如 ERP 的 64 位 ODBC 驱动。
  • 如果读取的是共享文件夹里的文件，确认这台电脑和连接所用的账户都能打开它。

原因 5

防火墙或代理拦截了网关

登录网关应用时提示“Network request returned unexpected error”，或刷新失败并提示“Unable to connect to the remote server”。

  • 在网关应用中进入“诊断”，运行网络端口测试。
  • 网关只需要出站连接：443、5671-5672 和 9350-9354，不需要开放任何入站端口。
  • 如果代理只放行 80 和 443 端口，请在“网络”页开启 HTTPS 模式。

原因 6

合并了隐私级别不同的数据

在 Power BI Desktop 里刷新正常，但在服务中失败，提示“Information is needed in order to combine data”。

  • 这发生在合并多个数据源、并勾选了“始终忽略隐私级别设置”的报表上，而服务里没有这个选项。
  • 在 Power BI Desktop 的“选项 > 隐私”中，把“全局”和“当前文件”里的这个选项都取消。
  • 重新发布，并在服务中把隐私级别设为“组织”。

修复

解决根本原因：网关服务、连接、凭据或 Power Query 步骤。

把网关放对地方

如果装在笔记本电脑上，就迁到一直开机的服务器上，并妥善保存恢复密钥。

保持最新

更新到最新版本，并写下每月更新的方法。

减少依赖

如果数据是 Excel 文件，就迁到 SharePoint 或 OneDrive，它们不需要网关。

常见问题

什么是 Power BI 数据网关？
一个安装在你网络内某台电脑上的 Windows 程序，在你的数据和 Power BI 服务之间搭起桥梁。它只建立出站连接，所以不需要在你的网络上开放入站端口。
数据在 SharePoint 或 OneDrive 上，还需要网关吗？
不需要。SharePoint、OneDrive 和 Azure SQL 等云数据库可以直接从服务连接。网关是给你网络内部的东西用的：服务器、ERP 或共享文件夹。
网关会自动更新吗？
不会。微软每个月发布一个新版本，并且只支持最近的六个版本，所以需要不时手动安装更新。
