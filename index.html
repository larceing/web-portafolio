Producto propio · 2026

Gestor de incidencias, horas y facturación

Problema
Las incidencias se apuntaban a mano, las horas en una hoja de cálculo y las facturas aparte. Nada estaba conectado.
Qué hice
Una aplicación web propia donde cada incidencia lleva su seguimiento, su documentación, sus sesiones de trabajo cronometradas y su facturación. Usa MantisBT como motor de incidencias a través de su API, sin tocar su código.
Resultado
Historial migrado y cuadrado al céntimo, circuito proforma → factura → cobro, correo transaccional y 181 pruebas automáticas que recorren cada cambio de estado.
  • Node.js
  • MariaDB
  • API REST
  • Docker
  • Nginx

Para Grupo SPSIL · 2026

Gateway de datos en tiempo real

Problema
El almacén necesitaba ver el stock real desde una web, pero las bases de datos están en la red interna y no se podían abrir puertos hacia fuera.
Qué hice
Un gateway al estilo del de Power BI: un agente dentro de la red abre un túnel WebSocket hacia la web, consulta MariaDB y SQL Server cuando alguien lo pide y devuelve el dato por ese mismo túnel.
Resultado
Stock al momento en pantallas táctiles de nave, permisos por departamento, interfaz en español, chino e inglés y exportación a Excel.
  • Python
  • Django Channels
  • WebSocket
  • SQL Server
  • MariaDB

Producto propio · en desarrollo

CRM de citas con tablet sin conexión

Problema
Un negocio que gestiona citas de pacientes en hospitales trabajaba con una aplicación sobre hojas de cálculo que se quedaba corta, y en los hospitales no siempre hay cobertura.
Qué hice
La reescribí como aplicación web con base de datos propia y una app de tablet que funciona sin conexión: guarda en local, encola los cambios y los sincroniza por eventos con control de versiones cuando vuelve la red.
Resultado
Agenda, pacientes, servicios, cobros, documentos y alarmas en un solo sitio, con pantalla de conflictos para decidir cuando dos dispositivos cambian lo mismo. Desplegado en servidor propio.
  • Next.js
  • TypeScript
  • PostgreSQL
  • Prisma
  • React Native
  • Docker
