Sobre mí

Soy Henry Arce, analista de datos y desarrollador en Alicante, y fundador de Arce Data Lab. Trabajo con datos desde 2019, primero en consultoras y hoy dentro de la industria.

Arce Data Lab

Arce Data Lab es el laboratorio desde el que construyo aplicaciones, cuadros de mando y asistentes de IA para pymes e industria, con su propia plataforma de despliegue, correo y documentos. Todo lo que ves en los proyectos marcados como producto propio vive allí.

Mi infraestructura

Lo que tengo montado y mantengo yo, y donde viven mis aplicaciones y las de mis clientes

No dependo de plataformas cerradas: tengo un servidor propio con todo lo necesario para poner una aplicación en marcha con seguridad, probarla y pasarla a producción.

Servidor propio
Linux con Docker en Hetzner (Alemania, UE). Cada aplicación en su contenedor, detrás de un único proxy con HTTPS.
Entornos DEV y PRO
Cada app se prueba antes de llegar a producción, con «Volver a la anterior» en un clic y vuelta atrás automática en las apps que despliega el propio servidor.
Inicio de sesión único
Keycloak para todas las aplicaciones, con grupos por app y por entorno.
Dominios y certificados
Nginx Proxy Manager con HTTPS de Let's Encrypt y, en los dominios que están en Cloudflare, el DNS se crea solo.
Correo con marca
Servicio Mail sobre Resend: las apps envían desde soporte@arcedatalab.com, con SPF, DKIM y DMARC.
Documentos PDF
Report Server para facturas, pedidos y albaranes desde plantillas.
Despliegue continuo
GitHub Actions construye cada versión y la publica en GitHub Container Registry.
Copias y avisos
Copias nocturnas de las bases de datos de las apps principales y comprobación continua de que cada app responde.
