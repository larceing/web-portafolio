Open source · Arce Data Lab · 2026

In-house platform to deploy apps to DEV and PRO

Problem
Every application was deployed by hand on the server, each with its domain, login and backups done a different way.
What I did
A system that gives each app a test environment and a production one on the same server. An app plugs in with a manifest file and the system creates its route, its Keycloak user group, its domain with a certificate and its deployment from the GitHub image.
Result
About ten applications living on one server, “Deploy”, “Promote to PRO” and “Roll back” buttons, automatic rollback for the apps the server deploys, and an agent that updates itself when the tests are green.

Python · FastAPI · Nginx · Keycloak · Docker · GitHub Actions · Cloudflare
