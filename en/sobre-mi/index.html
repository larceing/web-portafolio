My infrastructure

What I run and maintain myself, where my apps and my clients’ apps live

I don’t depend on closed platforms: I run my own server with everything needed to launch an application securely, test it and promote it to production.

Own server
Linux with Docker on Hetzner (Germany, EU). Each app in its own container, behind a single HTTPS proxy.
DEV and PRO environments
Every app is tested before it reaches production, with one-click “Roll back” and automatic rollback for the apps the server deploys itself.
Single sign-on
Keycloak for every application, with groups per app and per environment.
Domains and certificates
Nginx Proxy Manager with Let’s Encrypt HTTPS and, for domains on Cloudflare, DNS records created automatically.
Branded email
A Mail service on top of Resend: apps send from soporte@arcedatalab.com, with SPF, DKIM and DMARC.
PDF documents
Report Server for invoices, orders and delivery notes from templates.
Continuous deployment
GitHub Actions builds every version and publishes it to GitHub Container Registry.
Backups and alerts
Nightly backups of the main apps’ databases and continuous checks that every app responds.
