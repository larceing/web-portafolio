Your Power BI report isn’t refreshing: causes and fixes

You open the report and the data is from yesterday, or you get a “refresh failed” email. It is almost always one of these six causes, and most take minutes to fix. Start with the semantic model’s refresh history in the Power BI service: the error message is there. If you can’t find it, I’ll go through it with you.

The six most common causes

From most to least frequent. For each one, the clue that gives it away and what to do.

Cause 1

Expired credentials

Someone changed the password of the database, of Microsoft 365 or of the user the report connects with.

  • In the Power BI service, open the semantic model settings, go to “Data source credentials” and sign in again.
  • Use a service account whose password doesn’t expire, instead of a person’s.

Cause 2

The gateway isn’t responding

The data comes from a company server or folder, and the error mentions the gateway.

  • Check that the machine it’s installed on is switched on, connected and not asleep.
  • Update it: Microsoft releases a new version almost every month.
  • Better on a server than on someone’s laptop.

Cause 3

A file was moved or renamed

The report reads an Excel or CSV file and someone changed its folder, name or sheet.

  • Point to the new path in Power Query, under “Data source settings”.
  • Keep the files in SharePoint or OneDrive and connect by their web address: then no gateway is needed.

Cause 4

A column changed

The error says a column can’t be found (“The column … of the table wasn’t found”).

  • Someone renamed or removed a column in the Excel file or the ERP view.
  • Adjust the Power Query step that uses it, or agree that the source keeps its names.

Cause 5

The schedule switched itself off

The report stopped refreshing with no new errors and the scheduled refresh shows as disabled.

  • Power BI disables it after four failures in a row, and pauses it if nobody opens the report for two months.
  • Fix the cause, open the report and switch the schedule back on.

Cause 6

It takes too long

The error mentions a timeout or size.

  • With Power BI Pro, each scheduled refresh can run for two hours at most.
  • Remove unused columns and rows, filter at the source and consider incremental refresh.

Frequently asked questions

Why isn’t my Power BI refreshing today?
Look at the semantic model’s refresh history first: the error message usually tells you the cause. The most common ones are expired credentials, a gateway that is off or a file that has been moved.
What if the problem is Power BI itself?
It happens, though rarely. Check the Power BI service status page. If there is an incident, don’t touch anything: refresh works again once Microsoft fixes it.
How many times a day can it refresh?
With Power BI Pro, up to 8 scheduled refreshes a day. With Premium Per User or a Fabric capacity, up to 48.
How much does it cost for you to fix it?
It depends on the cause. Tell me which error you get and I’ll send you a fixed quote before starting, with no obligation.
