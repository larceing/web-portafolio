Power BI gateway error: causes and fixes

The data gateway is the program that lets the Power BI service read the data you keep inside the company: a SQL Server, the ERP or a shared folder. When it fails, the report doesn’t refresh. It is almost always one of these six causes. Start with the message in the refresh history and the Status tab of the gateway app. If you can’t find it, I’ll go through it with you.

The six most common causes

For each one, the clue that gives it away (usually the error text) and what to do.

Cause 1

The gateway is offline

The error says “Your data gateway is offline or couldn’t be reached”, or it shows as offline in “Manage connections and gateways”.

  • Check that the machine it’s installed on is switched on, online and not asleep. Microsoft advises against installing it on a laptop.
  • Open the gateway app and restart it from “Service Settings”.
  • If nobody has touched it for months, update it: Microsoft only supports the last six releases.

Cause 2

The data source connection is missing

When you schedule the refresh you can’t pick the gateway, or the error says no gateway is configured for the data sources.

  • In “Manage connections and gateways”, create a connection for each company source the report uses, all on the same gateway.
  • Type the server and database exactly as in Power BI Desktop: if you used an IP address or SERVER\INSTANCE there, use it here too.
  • Ask the admin to add you as a user of the connection.

Cause 3

Wrong credentials in the connection

The error says “Invalid connection credentials” or “Login failed for user”.

  • With a gateway, the credentials don’t live in the semantic model: you change them in the connection, under “Manage connections and gateways”.
  • Check that the authentication method (Windows or Basic) is the one the source expects.
  • Use a service account whose password doesn’t expire.

Cause 4

It reaches the gateway, but not the source

The error says “We reached the data gateway, but the gateway can’t access the on-premises data source”, or you see the code DM_GWPipeline_Gateway_DataSourceAccessError.

  • Open Power BI Desktop on the gateway machine and refresh the report there: if it fails there, the problem is on that machine.
  • Install on that machine the drivers the source needs, such as the ERP’s 64-bit ODBC driver.
  • If it reads files from a shared folder, check that the machine and the connection’s account can open it.

Cause 5

The firewall or proxy blocks it

Signing in to the app shows “Network request returned unexpected error”, or the refresh fails with “Unable to connect to the remote server”.

  • In the app, go to Diagnostics and run the network ports test.
  • The gateway only needs outbound connections: 443, 5671-5672 and 9350-9354. No inbound ports have to be opened.
  • If the proxy only lets ports 80 and 443 through, turn on HTTPS mode in the Network tab.

Cause 6

Data with different privacy levels is combined

It refreshes fine in Power BI Desktop, but in the service it fails with “Information is needed in order to combine data”.

  • It happens in reports that combine several sources with “Always ignore privacy level settings” on, an option the service doesn’t have.
  • In Power BI Desktop, turn that option off under Options > Privacy, both in Global and in the current file.
  • Publish again and set the privacy level to “Organizational” in the service.

Frequently asked questions

What is the Power BI data gateway?
A Windows program installed on a machine in your network that acts as a bridge between your data and the Power BI service. It only opens outbound connections, so no inbound ports have to be opened in your network.
Do I need a gateway if my data is in SharePoint or OneDrive?
No. SharePoint, OneDrive and cloud databases such as Azure SQL connect directly from the service. You need it for what is inside your network: a server, the ERP or a shared folder.
Does the gateway update itself?
No. Microsoft releases a new version every month and only supports the last six, so you have to install it by hand from time to time.
